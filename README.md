## Local preview

Download or clone the repository, then open `index.html` in a modern browser. No dependencies or installation required.

## Deploy to GitHub Pages

1. Upload the files into the **root** of a public GitHub repository named `smilecare-clinic`.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch → main → /(root)** and save.
4. Visit [the published URL](https://som3aamm.github.io/smilecare-clinic/) once GitHub Pages finishes deploying.
